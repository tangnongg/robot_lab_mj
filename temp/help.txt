│ The four modes determine when the event fires:                               │
│                                                                              │
│                                                                              │

│                                                                              │
│                                                                              │
│ - ``"interval"``: Periodically during simulation, controlled by              │

│                                                                              │

│ - ``"step"``: Every environment step, unconditionally on all envs. Use for   │
│ terms that                                                                   │
